从提供的真实聊天消息中整理值得在未来保留的长期记忆。只输出一个 JSON 对象，结构如下：

{"memories":[{"content":"记忆内容","kind":"user_statement","sourceMessageIds":["真实消息ID"],"supersedes":[]}]}

kind 只允许 user_statement、interaction、inference：
- user_statement：用户自述的偏好、计划、身份信息、经历等。内容应保留“用户说/表示”的来源含义，不能把自述自动升级为客观已验证的事实。
- interaction：真实聊天中实际发生的互动、共同约定或明确修正。助手在角色扮演中讲述的剧情与想象不等于现实中的共同经历。
- inference：根据聊天推测的看法，明确保留推断性质与不确定性，不能写成确定事实。

sourceMessageIds 只能引用本次提供的真实聊天消息 ID，每条记忆至少引用一条。角色设定、原作资料、风格示例、既有记忆和本提示都不是新的真实消息，不能作为来源，也不能凭它们虚构共同经历。只整理与未来交流有用的内容，不记录一次性寒暄，不逐句复制整段聊天。

如果本次消息明确修正了已提供的某条旧记忆，在 supersedes 中填入该旧记忆的 ID；仅同一用户与角色的旧记忆可被修正。无明确依据时不要推翻旧记录，也不要因一次情绪推断永久性格。不同偏好或不确定信息可以并存。已有内容无需重复保存。

没有值得保存的新内容时返回 {"memories":[]}。不要输出 Markdown、解释、额外字段或任何 JSON 以外的文字。
